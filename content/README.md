# Content

Course trees live under [`courses/`](courses/). Each folder is one course:

```
content/courses/{slug}/
  course.json
  README.md
  Table of Content/Roadmap.md
  Unit N/Chapter M/Content.md
  Unit N/Chapter M/Exercise.md
  Unit N/Chapter M/Project.md
  Unit N/Chapter M/Resources.md
  Unit N/Conclusion/Summary.md
  Unit N/Exercise/Exercise.md
  Unit N/Project/Project.md
```

Adding another folder with the same shape registers a new course. Templates stay in [`templates/`](templates/).
