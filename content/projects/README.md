# Chapter Project Catalogs

Each course has one canonical project catalog in this directory. Catalogs follow the learner-facing order Course → Unit → Chapter and contain exactly one required applied project for every displayed chapter.

The shared project workflow, compatibility anchors, and course index remain in [`../guides/Projects.md`](../guides/Projects.md). Existing unit projects and course capstones are retained as additional synthesis work; they do not replace or gate chapter projects.

Run `npm run audit:projects` after changing curriculum chapters, lessons, or project cards. The audit checks canonical ordering, exact lesson coverage, navigation links, required project fields, and repository-wide totals.
